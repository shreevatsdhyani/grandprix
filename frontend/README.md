# Frontend — The Silent Co-Driver

React + Vite + TypeScript + Tailwind. See the root [README](../README.md) and
[SETUP.md](../SETUP.md) for full setup and run instructions.

```
cd frontend
npm install
npm run dev        # dev server on :5173 (proxies /api → :8000)
npm run preview    # built bundle on :4173 (same proxy)
```
